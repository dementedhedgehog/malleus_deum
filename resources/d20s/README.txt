
The process to produce these images is as follows:

   i) Find the icons to use at game-icons.net (e.g. https://game-icons.net/1x1/delapouite/shamrock.html and https://game-icons.net/1x1/lorc/plain-dagger.html)
   ii) Set the foregrounds to black and the backgrounds to 100% transparency (and circular).
  iii) Download as svg.
   iv) Go to https://baronofdice.com/en-au/products/custom-d20
    v) Drop in icon, select the colours, and fiddle till you're happy.
   vi) Screenshot the page
  vii) Edit in gimp.
 viii) Drop into inkscape.
